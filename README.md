# Tidya Design Guide

Designspråk for Tidya: farger, typografi, komponenter og tokens, med mørk og lys modus.

- `index.html`: visuell guide (åpnes direkte i nettleser)
- `tokens.css`: CSS-variabler (kilde til sannhet for farger, radius og bevegelse)
- `styles.css`: stiler for selve guiden
- `theme.js`: bryter for mørk/lys modus

Alle tekstfarger er kontrastsjekket mot WCAG AA (4,5:1) mot `--color-bg`.
